How Cursor Pro data is treated

Hooks can indicate agent activity but do not prove exact token spend. The MVP accepts documented usage exports or manually supplied figures. Never fabricate missing token counts or treat simulated activity as billed usage. Paid subscription cost should be allocated using a chosen accounting method, not added on top of identical underlying model usage.

Tracking & idle rules

Applied to the local tracker when eventually connected.

Task time counts the combined intervals where editor work OR an agent run is active. An idle user does not pause a running agent. With neither active, task time pauses. Overlapping intervals count once.
